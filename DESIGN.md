# Muse Dogs — Design System

Redesign spec, 2026-10-13. The build follows this file. Presentation only:
every functional ID, script, data path, and behavior is preserved from the
previous site; only markup structure, styling, and copy length change.

## Standard

Apple-grade cleanliness, Muse Dogs' own identity. One idea per viewport,
confident type, vast negative space, chrome that nearly disappears, imagery
unboxed and given room. If an element can be removed without losing meaning,
it is removed. No gradients, no glass, no glow, no emoji bullets, no
decorative cards. This must read as a professional studio's work.

## Identity

"The town dog, set in type." Warm paper white, near-black ink, one deep
brass accent (the lantern, refined). The dog art carries all the warmth;
the design around it stays quiet so the art is the personality.

## Type

- Display: **Space Grotesk** (500/600), tight tracking (−0.03em). Headlines
  are statements, not labels: hero `clamp(2.9rem, 6.5vw, 4.6rem)`,
  page titles `clamp(2.4rem, 5vw, 3.6rem)`, section heads
  `clamp(1.9rem, 3.6vw, 2.6rem)`.
- Body: **Inter** (400/500/600), `1rem/1.65`, measure ≤ 62ch.
- Labels: 11px uppercase, 0.16em tracking, brass or ink-3 — used sparingly.
- Code/addresses: ui-monospace stack.
- Lede: `1.25rem`, ink-2, one or two sentences maximum.

## Layout & chrome

- One `.wrap` (1120px, 24px gutters). Sections separated by whitespace
  (`clamp(72px, 10vw, 120px)`) and the occasional hairline — not boxes.
  Cards exist only where function demands: the board, claim/lookup panels,
  forms, fact tables.
- Header: 60px, translucent paper + hairline. Wordmark (logo + "Muse Dogs"
  in Space Grotesk). No top strip.
- Footer: hairline top, small type (13px), full site map, one bottom line.

## Navigation map

- Primary nav (5): **Rewards · Mint · Porch · Why · API**
- Primary action (1): **Register** — brass pill button.
- Depth (footer + in-page links only): Home (wordmark), Verify, Agent claim
  guide, Project Safe.
- Mobile: one Menu button → panel with the 5 links, Register, then Verify,
  Agent claim, Safe. Current page is marked in ink, not with checkmarks.

## Components

- Buttons: pill. Primary = brass fill, white text. Secondary = hairline
  border, ink text, transparent fill. Small variant for table rows.
- Pills/badges: hairline border, micro type. `.pill.live` = green dot.
- Facts: two-column definition rows divided by hairlines (no table chrome).
- Board (rewards): the site's one dark surface — ink panel, hairline rows,
  gold only for rank and reward figures. All `lb-*` classes generated by
  leaderboard.js are styled here; the JS is untouched.
- Forms: labels above inputs, 44px+ targets, hints in ink-3, results as
  quiet bordered notices (`.result-ok` / `.result-err`).
- Motion: color/opacity transitions ≤ 160ms. Nothing else moves.

## Truthfulness (unchanged, non-negotiable)

Voucher mint — never an automatic/gasless airdrop. Caps: 3 per address
AND 3 per verified muse identity (6 total across both paths). Royalty ETH
buys back MDOG; resulting LP positions go to the dead address — never a
literal MDOG burn. No treasury/Safe addresses published anywhere. Holder
rewards: claimed, never airdropped; epoch 1 = Oct 12–18, claims open after
funding + root publish (Oct 19).

## Preservation checklist

- Gate: none exists to preserve — the passcode gate was removed at public
  launch (commit `f8525dfe`, in HEAD). The redesign adds no gate logic.
- JS untouched: `app.js`, `claim.js`, `leaderboard.js`, all inline scripts.
- Every element ID referenced by any script survives (audited by diffing
  id sets before/after).
- Static data stays under `site/data/v1/`; `api/` server code untouched.
- Vanilla HTML/CSS/JS. No build step. No new imagery — existing repo art
  only.
