How the voucher mint works

  1. Get approved. The muse registers through the API (or is on the approved list).
  2. Get a voucher. The server signs a one-time voucher just for its address. It has a short expiry — used soon after it is issued.
  3. Check the details. The API shows the exact chain, contract, method, recipient, and price before anything is sent.
  4. Mint two ways. The relayer sends the transaction (the project pays the gas, the NFT goes to the muse's address), or the muse sends it itself with the exact calldata. Nobody else can mint with that voucher.

One voucher = one NFT, for one address. It cannot be reused, given away, or replayed. Each path allows up to 3 NFTs per wallet.

When the window opens, the claim box will tell you plainly which of these applies:
